example / plain DOM

No framework, no build, no assets.

Five blocks, and between them they use the whole grammar. Every sound below is synthesized on the spot from one theme object: nothing is fetched, and no two presses render the same waveform.

This page imports the built package and could not find it. Run npm run build (or ./serve.sh, which does it for you) and reload.

01

Bind it and forget it

One call wires every element carrying a data-anti attribute. For a button whose meaning is already in the markup, this is the entire integration: no handlers, no imports at the call site.

The disabled button is silent on purpose: nothing happened, so nothing is said. A control that refuses out loud is a different case, and it is a locked one.

import Anti from 'anti-tapes'

Anti.bind()   // every [data-anti], wired

<button data-anti="commit">Save</button>
<button data-anti="reject">Cancel</button>
<button data-anti="tick">Next</button>
02

A mechanism gets a pair

A switch is discrete: it is taken hold of and it lands. That is the one-shot pair, grab on the press and a verdict on the landing, and it is the shape a keyboard key, a checkbox, and a segmented control all take.

Off

sw.addEventListener('pointerdown', () => {
  Anti.play('grab')          // taken hold of
})

sw.addEventListener('click', () => {
  const on = toggle()
  // It landed. Off is a landing too, and a
  // quieter one: it resolves lower.
  Anti.play('commit', { value: on ? 0.7 : 0.35 })
})
03

A drag is one gesture, so it is one sound

Continuous change is a held drone that glides with the value. The onset is the grab and the decay is the release, so a drag starts with drone.start alone and ends with drone.stop alone. Layering a pluck at either end is the most common way to get this wrong: two sounds read as two events.

Level 0.50

Drag it, then tab to it and use the arrow keys. A keyboard user is not dragging: they are stepping, so each notch gets its own pluck instead of a held voice. The gesture decides the sound, not the widget.

lvl.addEventListener('pointerdown', () => {
  dragging = true
  Anti.drone.start('level', norm())   // the grab
})

lvl.addEventListener('input', () => {
  if (dragging) {
    Anti.drone.move('level', norm())  // glides
  } else if (performance.now() - last > 40) {
    last = performance.now()          // keyboard: a
    Anti.play('grab', { value: norm() })  // pluck per notch
  }
})

// pointerup, and pointercancel, which is the one
// every implementation forgets and then leaks a
// held voice on.
const end = () => {
  if (!dragging) return
  dragging = false
  Anti.drone.stop('level')            // the release
}
window.addEventListener('pointerup', end)
window.addEventListener('pointercancel', end)
04

Loading that resolves when it lands

A progress run is a voice-led figure that arrives exactly at 100%: the lead climbs the ladder, a bass walks the quarters, and a reference tone beats slower as it closes. done resolves it. stop abandons it without resolution, which is what a cancel actually sounds like.

Stateidle

Indeterminate is a real state and it sounds like one: hold rocks between two rungs with no reference tone, because a reference is a promise of resolution and this state makes none.

Anti.progress.start('upload', 0)

// as the bytes land
Anti.progress.set('upload', 0.4)

// no ETA to give
Anti.progress.hold('upload')

Anti.progress.done('upload')   // resolves
Anti.progress.stop('upload')   // abandons
05

The tier that speaks without being asked

Four notifications, and their shapes are their meanings. Success ascends and resolves. Info is a calm consonant ping. Warning oscillates and ends unresolved, with a faint beat left in the air. Error falls and lands in a beating cluster, which is the one place a charged waveform earns its keep.

Fire them in a row. The repetition governor thins fast repeats of the same event and lets them recover over about a second of quiet, so a retry loop cannot turn into a jackhammer.

Anti.play('success')
Anti.play('info')
Anti.play('warning')
Anti.play('error')

// The sight and the sound name the same tier,
// so they cannot drift apart.
toast(tier, message)
