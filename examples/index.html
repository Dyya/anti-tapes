examples

Eleven events cover an interface.

That is the claim, and these four pages are the proof rather than the argument. Each takes one interaction family, maps it onto the grammar the engine already has, and says out loud which calls were judgment rather than mechanics.

All four import the package the way an app does, with a bare anti-tapes specifier. The only line here that is about this repo is the import map that resolves it, and in your app your bundler does that instead.

These pages import the built package and could not find it. Run npm run build (or ./serve.sh, which does it for you) and reload.

on running these

These are the one thing here that needs a server

Every other surface in this project opens straight from the filesystem. These do not, and the reason is the point of them: they import the package over a bare specifier, which browsers only resolve over http. ./serve.sh builds the package and serves the repo in one command.

./serve.sh
# then http://localhost:8477/examples/
